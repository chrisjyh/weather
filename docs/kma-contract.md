# 기상청 API 고정 기준

2026-10-23에 [공공데이터포털 공식 서비스](https://www.data.go.kr/data/15084084/openapi.do)의
`기상청41_단기예보 조회서비스_오픈API활용가이드_2610.zip`을 확인했습니다.
ZIP 내 DOCX 수정일은 2026-10-19입니다. API Hub의 별도 엔드포인트와 혼용하지 않습니다.

- 호스트: `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/`
- 연산: `getUltraSrtNcst`, `getUltraSrtFcst`, `getVilageFcst`
- `dataType=JSON`, `numOfRows=2000`, `pageNo=1`, Decoding 키를 Retrofit 쿼리로 1회 인코딩
- 모든 발표/예보 시각 계산: Asia/Seoul

| 자료 | 선택하는 base_time | API 제공 이후 |
|---|---|---|
| 실황 | 매시 HH00 | HH:10 |
| 초단기예보 | 매시 HH30 | HH:45 |
| 단기예보 | 02/05/08/11/14/17/20/23시 00분 | 각 발표 +10분 |

발표 직후 30분 동안 NO_DATA일 때만 이전 발표를 한 번 조회합니다. 인증/쿼터 오류는 즉시 중단합니다.
실황/초단기는 동일 발표 내 일부 요소가 10분 간격 갱신될 수 있습니다. MVP 자동 갱신은 성공한
동일 발표를 재사용하며 수동 갱신으로 동일 발표를 재조회합니다.

| 코드 | 매핑 |
|---|---|
| T1H / TMP | 실황·초단기 / 단기 기온 |
| SKY | 1 맑음, 3 구름많음, 4 흐림 |
| PTY | 0 없음, 1 비, 2 비/눈, 3 눈, 4 소나기, 5 빗방울, 6 빗방울눈날림, 7 눈날림 |
| POP | 강수 확률 (0–100); 최신 가이드에는 초단기 POP도 포함 |
| PCP / RN1 | 1시간 강수량; 문자열 범주 보존 |
| TMN / TMX | 예보 날짜의 공식 최저 / 최고 |

±900 이상 수치는 결측입니다. 필드 자체의 누락을 무강수·맑음·0도로 바꾸지 않습니다.
강수량 필드에 명시된 0/`-`/`강수없음`은 무강수입니다. 숫자 강수량은 공식 범주(1mm 미만,
30.0~50.0mm, 50.0mm 이상)로 표시하고 이미 범주인 문자열은 유지합니다.

오류: 03 자료 없음, 20/21/30–33 인증·서비스키, 22 호출량 제한, 05 시간 초과.
HTTP 상태와 XML 게이트웨이 오류도 별도로 처리합니다. 응답 본문/URL은 오류 메시지에 포함하지 않습니다.

관련 코드: `KmaTime.kt`, `KmaApi.kt`, `WeatherMapper.kt`.
경계와 오류 응답 fixture는 `data/src/test`에 고정했습니다.
